# 構成と必要なもの

Lista を自分の組織で動かす前に、全体の形と、用意するものを確かめてください。

## 全体の形

```
利用者のブラウザ ──https──▶ リバースプロキシ ──http://127.0.0.1:8080──▶ Lista（webapp）──▶ PostgreSQL
                                                              │
                                                              ├─https──▶ OIDC のプロバイダ（ログイン）
                                                              ├─https──▶ api.anthropic.com（任意。メールからの下書き）
                                                              ├─http───▶ ntfy（任意。スマートフォンなどへの通知）
                                                              └─UDP 2425──▶ 各 PC の IP メッセンジャー（任意）
```

- Lista は 1 つのコンテナ（webapp）で動きます。毎月のシートの作成や朝のまとめのような定期処理も、このコンテナの中で動きます
- データはすべて PostgreSQL に入ります。添付したファイルも DB に入ります。バックアップするのは DB だけです（[バックアップと復元](backup.md)）
- Lista は 127.0.0.1 だけで待ち受けます。利用者は、同じホストのリバースプロキシを https で開きます（[リバースプロキシと https](reverse-proxy.md)）
- 配布元へは何も送りません。外への通信の一覧は [データの送り先](data-flows.md) にあります

## 必要なもの

| もの | 要るか | 説明 |
|---|---|---|
| Docker と Docker Compose | 必須 | `docker compose` が動くこと。イメージは `ghcr.io/propagandist/lista` から取得します |
| メモリ | 必須 | Lista に 512 MB ほど、PostgreSQL に 100 MB ほどを見込んでください（下の「メモリ」） |
| OIDC のプロバイダ | 必須 | Microsoft Entra ID・Keycloak など、OpenID Connect でログインできるもの（[ログインの設定](oidc.md)） |
| https のリバースプロキシと証明書 | 必須 | ブラウザが信頼する証明書で https を出すもの。手元で試すだけなら要りません |
| IP メッセンジャー | 任意 | 朝のまとめと担当の通知を、各 PC の IP メッセンジャーへ送ります（[通知の設定](notifications.md)） |
| ntfy のサーバー | 任意 | 同じ通知を、スマートフォンや PC の ntfy アプリへ送ります。同梱の compose で立てられます |
| Claude API の鍵 | 任意 | Outlook のメールから、AI が突発タスクを下書きします（[AI の下書き](ai.md)） |
| Microsoft 365 の Outlook | 任意 | Outlook のアドインを使うとき（[Outlook アドイン](outlook-addin.md)） |

## 決まっていること

導入の前に、次の前提が自分の組織に合うかを確かめてください。設定では変えられません。

- **画面と通知は日本語だけです。** 時刻は日本時間（Asia/Tokyo）で扱います
- **祝日と会社休業日は、画面の「休日」に登録した日だけを見ます**（[休日](../user/holidays.md)）。祝日は内閣府の CSV を取り込みます。Lista が自分で取りに行くことはありません
- **1 台で動かします。** 同じ DB に Lista を 2 台つなぐと、定期処理と通知が重なります
- **利用者に役割（権限の差）がありません。** 登録した人は誰でも、利用者の追加やテンプレートの変更を含め、すべての操作ができます（[セキュリティ上の注意](security.md)）
- **ログインに使う IdP は 1 つです。** パスワードは Lista では持ちません

## メモリ

イメージの既定のヒープは 384 MB です（`JAVA_TOOL_OPTIONS` の `-Xmx384m`）。配布元の測定（2026-11-11）では、起動してログインした直後の使用量が、Lista のコンテナで 363 MiB、PostgreSQL で 45 MiB でした。月の記録の PDF は、同じコンテナの中で別のプログラム（Typst）が作ります。そのメモリは上のヒープの外で使い、同時に作るのは 2 つまでです。PDF を作るときの使用量は、配布元ではまだ測っていません。ログに `OutOfMemoryError` が出たら、`.env` の `JAVA_TOOL_OPTIONS` で `-Xmx` を上げてください。
