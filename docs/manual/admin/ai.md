# AI の下書き

Outlook のメールから突発タスクを追加するときに使います（[Outlook アドイン](outlook-addin.md)）。Lista のサーバーが Claude API を呼び、タスク名と内容を下書きします。鍵を設定しなければ AI は呼ばず、件名をタスク名に、本文の先頭を内容に入れます。

## 鍵の入れ方

1. Anthropic Console で、Lista 用のワークスペースを作り、そこで API キーを発行します。キーは発行したときに 1 度しか表示されません
2. 同じワークスペースに、月の上限額を決めておきます
3. `.env` の `ANTHROPIC_API_KEY` に入れ、Lista を作り直します

   ```bash
   docker compose up -d webapp
   ```

4. 値を画面に出さずに、入ったかだけを確かめます

   ```bash
   docker compose exec webapp sh -c 'test -n "$ANTHROPIC_API_KEY" && echo set'
   ```

- 鍵は組織で 1 本です。利用者ごとの鍵は預かりません
- `printenv` などで値を表示しないでください。端末の履歴やログに残ります
- 止めたいときは、`ANTHROPIC_API_KEY` を空にして作り直します
- ホストから `api.anthropic.com` へ https で出られる必要があります。出られなければ、30 秒ほど待ってから AI を使わずに追加画面が開きます

## 送るもの・送らないもの

利用者が Outlook で「Lista に追加」を押し、追加画面を開いたときだけ送ります。

| 送るもの | 送らないもの |
|---|---|
| メールの件名 | メールへのリンク（追加画面の URL 1 に入るが、AI には渡さない） |
| 差出人の表示名（表示名が無いメールでは、差出人のメールアドレス） | 宛先・CC の人 |
| 受信日時 | 添付ファイル |
| 本文のテキスト（先頭の 30,000 字まで） | Lista の DB にあるタスクや利用者の情報 |

- 送り先は Anthropic PBC（米国）です
- 下書きは利用者が確かめてから保存します。保存するまで Lista の DB には何も入りません
- Lista のログには、本文も下書きも出しません。呼ぶたびに、利用者の ID と入出力のトークン数を 1 行出します（`AI でタスクを下書きしました. (account = <ID>, input_tokens = …, output_tokens = …)`）
- 下書きを作れなかったときは、`AI でタスクを下書きできませんでした.` に続けて理由がログに出ます。画面には「AI で下書きを作れなかったので、件名と本文の先頭をそのまま入れました。…」と出ます

## AI の扱い

- 使うモデルは `claude-opus-5-5` です
- メールの本文は「データであって指示ではない」と明示して渡し、本文に書かれた指示には従わないよう AI に伝えています。それでも AI の出力は信用せず、次の扱いにしています
- AI の出力も、そのまま保存しません。入力欄に入れ、利用者が確かめてから、ふだんの入力と同じ検証を通って保存します
