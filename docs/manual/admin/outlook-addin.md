# Outlook アドイン

Outlook でメールを開き、「Lista に追加」を押すと、そのメールから突発タスクの追加画面が別のウィンドウで開きます。タスク名と内容は AI が下書きします（AI の鍵が無ければ、件名と本文の先頭がそのまま入ります）。利用者が値を確かめて保存するまで、Lista には何も書かれません。

新しい Outlook（デスクトップ）と Outlook on the web で使えます。

## 前提

- Lista を https で開けること（[リバースプロキシと https](reverse-proxy.md)）。Outlook は https のページしか開きません
- `.env` の `LISTA_BASE_URL` が、利用者が開く https の URL になっていること。マニフェストの中の URL はこの値から作ります
- Microsoft 365 の商用のクラウドの Outlook であること。Lista が埋め込みを許しているのは `outlook.office.com`・`outlook.office365.com`・`outlook.cloud.microsoft` だけです
- 利用者がカスタムのアドインを足せること。Exchange 管理センターのロールの割り当てのポリシーで、利用者に「My Custom Apps」が付いている必要があります

## 配り方

マニフェストは Lista が `<LISTA_BASE_URL>/addin/manifest.xml` で返します（ログインは要りません）。利用者に、次の手順を案内してください。アドインの使い方は [利用者ガイドの突発タスク](../user/adhoc.md) にあります。

1. ブラウザーで `https://lista.example.com/addin/manifest.xml` を開き、ファイルとして保存します
2. Outlook on the web か新しい Outlook で、「アプリ」または「アドインを取得」を開きます
3. 「個人用アドイン」の「カスタム アドインを追加」から「ファイルから追加」を選び、1 のファイルを入れます
4. メールを開くと、リボン（または「…」のアプリの一覧）に「Lista に追加」が出ます

- 入れるのは 1 人 1 回です。新しい Outlook と Outlook on the web は同じアカウントなので、片方で入れれば両方に出ます
- 組織へまとめて配る手順（Microsoft 365 管理センターの統合アプリ）は、配布元では確かめていません

## 知っておくこと

- **AI の鍵を設定すると、メールの件名・差出人の表示名（無ければメールアドレス）・受信日時・本文が、Anthropic（米国）へ送られます。**詳しくは [AI の下書き](ai.md) と [データの送り先](data-flows.md) にあります。アドインの画面にも、この旨を出しています
- メールの中身は URL のフラグメント（`#` の後ろ）で別のウィンドウへ渡します。フラグメントはサーバーへ送られないので、リバースプロキシのアクセスログにメールの本文は残りません
- マニフェストのアドインの ID は、どの配布先でも同じです。1 つのテナントで 2 つの Lista を使う形は確かめていません
- Outlook が古いマニフェストを持ち続けることがあります。Lista の URL を変えたら、利用者に入れ直してもらってください
